THE CORE IDEA

One keyword. Many alphabet shifts.

The Vigenère cipher encrypts letters using a repeating keyword. Unlike a Caesar cipher, which applies one fixed shift, Vigenère uses different shifts based on the key letter.

01

Map letters to numbers

Assign A = 0, B = 1, and continue through Z = 25. This turns letters into values that can be calculated.

A 0· B 1· C 2… Z 25
02

Repeat the key

Repeat the keyword over alphabetic message characters. Spaces and punctuation remain unchanged and do not consume key characters.

MESSAGEHELLOWORLDKEYKEYKEYKEYK
03

Encrypt or decrypt

Combine message and key values using modular arithmetic, then convert the result back into a letter.

ENCRYPT
C = (P + K) mod 26
DECRYPT
P = (C − K + 26) mod 26

Advantages

  • Uses multiple substitution alphabets.
  • More complex than a single-shift Caesar cipher.
  • Useful for teaching modular arithmetic and classical cryptography.
  • Easy to demonstrate visually.

Limitations

  • Repeating-key patterns can be analysed.
  • Short or reused keys weaken the cipher.
  • Vulnerable to established cryptanalysis methods.
  • Not suitable for modern secure communication.
Educational use only
